Hisscore — Privacy Policy

Last updated: 2026-09-12

Hisscore is a Snake game. It works entirely offline and does not have a server, an account system, analytics, or ads. This page explains, in full, what that means for your data — because there isn't much to say.

What the app collects

Nothing. Hisscore does not collect, transmit, or share any personal data, usage data, or device identifiers. There is no backend for it to send data to.

What's stored, and where

Your high scores, top-5 leaderboard, cumulative stats, daily-challenge streak, and a short local crash log are stored only in this app's own storage on your device, using the platform's standard local-storage APIs. None of it leaves your device. Uninstalling the app deletes all of it.

Permissions

The release build requests one runtime permission: POST_NOTIFICATIONS, used solely to schedule a local reminder for your next Daily Challenge. That reminder is scheduled and delivered entirely on-device — no notification content or token is sent anywhere.

Third parties

Hisscore has no third-party analytics, advertising, or tracking SDKs. No data is shared with anyone, because none is collected in the first place.

Children's privacy

Because the app collects no data from anyone, it does not collect data from children either. The game is rated for all ages.

Changes to this policy

If this ever changes — for example, if a future update adds an online leaderboard — this page will be updated first, with a new "last updated" date above, before that feature ships.
